# IA in cantiere

Prototipo Streamlit per una tesi sulla formazione continua e la sicurezza nei cantieri.

## Come funziona
1. Carica PDF ufficiali nella barra laterale.
2. Scegli la lingua della risposta.
3. Fai una domanda.
4. L'app traduce la domanda in italiano per la ricerca, recupera i passaggi più pertinenti dai PDF e chiede a Gemini di rispondere esclusivamente usando quel contesto.
